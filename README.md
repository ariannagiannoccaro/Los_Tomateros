# Propuesta:
Propuesta 1: Plataforma de Gestión de Eventos Universitarios (EventUni)
Descripción: Sistema web para crear, inscribir y gestionar eventos universitarios (charlas, talleres, ferias), con calendario compartido, registro de asistencia QR y notificaciones push básicas.
Estructura del proyecto:
    Tecnologías: Frontend (Vue.js + Vuetify), Backend (Laravel o Flask), Base de datos (MySQL), QR (qrcode.js), Notificaciones (Web Push API).
    Hitos por semanas:
    1-2: Requisitos + diseño DB (eventos, usuarios, asistencias).
    3-6: CRUD eventos + calendario (Frontend + Backend).
    7-10: Registro QR + escaneo (Backend + Frontend).
    11-14: Notificaciones + reportes asistencia (todos).
    15-16: Pruebas + admin dashboard.

Factibilidad técnica: Alta - QR y push notifications son challenges interesantes pero bien documentados.
​Factibilidad temporal: MVP funcional en semana 8 (sin notificaciones).
Factibilidad recursos: Gratis total, datos reales de eventos universitarios fáciles de poblar.
